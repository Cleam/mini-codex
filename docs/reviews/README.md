# 每周 Review

使用 ISO 周：周一至周日，按 Asia/Shanghai 记录。每周有学习或核查活动时创建 `YYYY-Www.md`，控制在一页左右；没有证据的历史周不补造进展。补写记录要注明补写日期与来源。

- [2026-W35](2026-W35.md)：根据 Git 提交补写的初始化与 v0.1 实现记录。
- [2026-W43](2026-W43.md)：项目恢复检查与收尾计划。
- [模板](template.md)：每周复制填写，区分事实、个人理解和计划。

Review 记录当周变化；learning 解释原理；roadmap 管阶段状态。收尾时同步三者，避免把计划写成已完成。本文未创建自动提醒或定时任务。
